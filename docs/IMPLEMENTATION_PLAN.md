# برنامهٔ پیادهسازی CinderDock

> یادداشت محیط: فایل تصویر پیوستشده در پوشهٔ کاری قابل دسترسی نبود. طراحی بر اساس توصیف دقیق موجود در درخواست اجرا میشود: نوار کناری باریک و تیره، فضای زغالی، صفحهٔ آغازین خلوت، کادر مرکزی، گردی ملایم گوشهها، مرزهای ظریف و نارنجی گرم. هویت CinderDock کاملاً مستقل است.

1. **پایه:** مخزن عمومی موجود، ساختار Tauri 2 + React/TypeScript/Vite، فونت فارسی، متغیرهای طراحی، لوگو/آیکون اختصاصی، فایلهای قفل.
2. **هستهٔ Rust:** تنظیمات غیرمحرمانه، مخازن اسرار DPAPI، SQLite با مهاجرت، پروایدرها و مدلها، جریان پاسخ، حلقهٔ ابزار محدود، تأییدها، diff، محدودسازی مسیر/خروجی/زمان، ابزارهای وب و دسکتاپ اختیاری.
3. **رابط واقعی:** صفحهٔ آغازین، گفتوگو، جستوجو، تنظیمات، ویزارد پروایدر، انتخابگر مدل، پنل فعالیت/فایلها/ترمینال، حالتهای بارگذاری/خطا/قطع اتصال/خالی، RTL و فینگلیش، میانبرها.
4. **کیفیت:** تستهای واحد React و Rust، Clippy، بررسی TypeScript، ساخت Vite، تست دود روی اجراکنندهٔ واقعی `windows-latest`، تصویربرداری از رابط.
5. **انتشار:** بررسی افزایش نسخهٔ معنایی، ساخت NSIS و اجرایی قابل حمل، بستهٔ کد منبع از همان برچسب، `SHA256SUMS.txt`، یادداشت انتشار و چهار دارایی دقیق Release. بهروزرسانی درون برنامهای تا زمان وجود امضا و مدیریت امن کلید خصوصی غیرفعال میماند.
